## 系统中的调整

- 摄影任务按用途分别安排：首图陈列、场景纵深、卖点垂感中景；其余模块使用真实证据实拍。
- 支持最多三张已识别同色的原始参考图。第一张定义当前商品身份，其他图片只校验花型与工艺；未知色款保持单参考。
- 自动副图也筛选同色，颜色对照页可使用不同色款；缺少独立原图时不复制同一照片拼图。
- 首图保留手写。其余文案依据已填资料按用途分派，不把缺失材质、件数、填充和性能补成卖点。
- 首屏、纹理、工艺、花型、颜色和参数采用不同节奏，支持四种局部画面编排；切版不自动触发收费调用。
- 图片可放大至100%–200%，再调整位置；方图也能改变主体占比，避免顶部背景过多。辅助证据照片保留自己的裁切。
- 新增质量与1K/2K素材配置；既有配置默认自动/1K、密钥保持加密保存。

## 模型选择与契约

当前服务商公开提供图片模型 `gpt-image-2`，因此保留现有模型，调整质量与输入策划。用户选择的文案模型 `deepseek-v4.1-flash` 继续用于文案。

参数依据 [B.AI GPT Image 2 文档](https://docs.b.ai/zh-Hans/llmservice/image-models/gpt-image-2/)和 [OpenAI 图片生成文档](https://developers.openai.com/api/docs/guides/image-generation)。2K 请求主图为2048×2048、已适配 B.AI 详情为1536×2048。提示词遵循 API 请求比例，不在其他服务商方图内强制生成竖图边框。高质量设置发送 `quality=high`，不发送 GPT Image 2 不需要的 `input_fidelity`。

接口接受参数不等于实际返回同尺寸，真实出图的尺寸与生成数量另记在 `VERIFICATION.md`。生成的颜色、纹理和结构仍需对照上传实拍逐张检查。
