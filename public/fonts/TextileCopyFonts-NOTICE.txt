Bundled copy typography fonts
=============================

These fonts are self-hosted application assets. No system font is redistributed
and no third-party font CDN is contacted when the application renders copy.
All three fonts use the SIL Open Font License 1.1. The complete, unchanged
upstream licenses are included alongside the font files.

License: TextileKai-LICENSE.txt
The derivative font family and PostScript names have been changed to Textile Kai
and TextileKai-Regular, respecting the upstream Reserved Font Names. Copyright,
license and attribution records remain intact. No upstream endorsement is implied.
Only the Regular (400) face is bundled; heavier canvas text uses browser synthesis.

Conversion
----------
Converted from the pinned TrueType sources to WOFF2 using fontTools 4.66.1 and
Brotli 1.2.0. All upstream glyphs, outlines, weight variation data and OpenType
features are retained; no subsetting. The Kai naming changes described above are
the only semantic metadata changes. These files are provided as Web fonts, not
installed into the operating system.
